## BLUF
- [Issue](https://github.com/kubernetes/enhancements/issues/4815)
- When DRA was introduced, it enables device to advertise their attributes via `ResourceSlice`. This works for statically configured MIG partitions
- This does not work for dynamic MIG however because unlike statically configured MIG partitions, dynamic MIG means the partitions are not present by the time scheduling happens as the MIG partitions will have to be created on the fly
- KEP-4815 aim to enable DRA driver to advertise the potential MIG geometry(s) the host GPU could have to prevent k8s scheduler from scheduling overlapping MIG partitions
  - Example: potential MIG partitions advertised by DRA driver:
  ```
  B200 physical GPU capacity
  [0][1][2][3][4][5][6]

  3g candidate A
  [0][1][2]

  2g candidate B
        [2][3]

  1g candidate C
              [4]

  2g candidate D
                 [5][6]
  ```
  - Conflict if both candidate A and B both scheduled
  ```
  3g candidate A
  [0][1][2]

  2g candidate B
        [2][3]

              ^
          both need slice 2

  If 3g candidate A is allocated:

  [0][1][2] = consumed

  then 2g candidate B becomes invalid
  because it overlaps slice 2.
  ```
